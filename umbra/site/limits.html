01   Limits

What this does not know.

Umbra reports a lower bound. These are the reasons, stated rather than buried.

  • Read evidence is file and line-range based. A mention in the agent's text is attention, not reading, and is ranked as the weakest tier.
  • Graph edges are not complete. Reflection, dynamic dispatch and configuration are invisible, so umbra is a lower bound on what was unexamined. The sweep's leak reasons are how you see the gap.
  • Fault lines and beacons are matched by a regular expression window around the call-site line, not by a parser.
  • Ranking weights are hand set and printed. They are a heuristic, not a measurement.
  • One transcript adapter. An agent whose transcript carries no tool records gets the unknown state, which is the correct answer rather than a guess.
  • The examined set comes from tool activity. An agent that reads and edits through the shell leaves no event, so its work looks unexamined. Umbra found this in its own build and disclosed it rather than tuning it away.
  • Scrubbing is pattern based. Command prefixes and failure excerpts are matched by shape, and a shape can be missed.
  • A destructive test runner does what it says. The echo before execution is the only guard.
  • Worktrees are keyed by commit in a shared directory, so two checkouts of one repository collide on one worktree. A leftover from a deleted checkout is now removed and pruned first; one belonging to a different live checkout is still reused.
  • A check that has never been observed to fail is not yet a check. Everything named here has a test that plants what it is for. That is the standard, not a guarantee that nothing else passes for the wrong reason.
02   Security

What leaves the machine, and what never does.

01No transcript text

One named exception: the session-said sentence, scrubbed and capped at 200 characters. Everything else in a report is paths, symbol names, kinds, ranges, sequence numbers, timestamps and scrubbed command prefixes.

02No shell

Umbra never executes a command from a transcript. Test ids must match a strict pattern, anything else is dropped and listed as not runnable, and ids are passed as separate argv elements. There is no sh -c anywhere in it.

03No network

None in the default path. This site makes no request beyond its own files and works from file://. A report you drop into the viewer is parsed in your browser and never uploaded.

The scrubber is the only exit. Every renderer takes a value that only the scrubbing path can produce, and a test walks every generated artifact in the repository looking for home paths, addresses, token shapes and author names.

03   Not built

And why.

Adapters for other agents, which get the unknown state, correctly. Subagent transcripts. Live mode during a session and a blind-spot budget gate, because shadow-branch data is not documented output. Mutability analysis of callees, because nothing in the documented surface provides it. Coverage deltas, which need coverage tooling in the target repository. Trend dashboards. Cross-repository dependents. And Umbra never writes code: it shows the shadow, it does not fix it.

Umbra

Finds the code an AI agent's change affects but the agent never looked at. A plugin for the Entire CLI. Deterministic, offline, and there is no model anywhere in it.

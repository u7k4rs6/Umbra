02   What it found

Four confident answers that were wrong.

Every one of them came from a check that had only ever passed. Each now has a test that plants what the check is for and proves it fires.

01The gitignore that hid a package

A semantic diff showed umbra/cmd missing entirely. The second line of a gitignore written in the first commit, entire-umbra, matched the binary and also the directory its source lives in. Seven files had never been committed, through nine phases of green test runs, because the compiler reads the working tree and git reads the repository. A clone was the only symptom available, and nobody had made one.

02Umbra found its own blind spot

Run on the commit where it changed its own shadow.Build, all twelve dependents came back umbra. That reading is correct: the change was made with a shell command rather than the editing tool, so the session produced no read and no edit event. The examined set is built from tool activity. It is in the limitations rather than tuned away.

03Five leaks, one shape

Five scrubbing bugs were the same bug five times: an output path that wrote without going through the scrubber. Each was fixed where it was found, which fixed that path and left the shape. The renderers now take a value only the scrubbing path can produce, so a new output cannot skip it by omission.

04Tests that proved nothing

Four label-placement tests across eight scenarios were all built on one overlap function. Making it return false for every pair left every one of them passing. They had been proving determinism, not collision. The case that has to fail for the rest to mean anything is now written down.

03   Disclosure

Who wrote what.

The agent

All product code across every phase was written during the build with an AI coding agent, captured in Entire checkpoints. That includes the tests, this site, the corona renderer and every document in the repository except the four planning documents, which were written before the build with AI assistance and are the first commit.

The human

The problem, the settled decisions in the kickoff, the scope of every phase, the decision to keep the repository private, and the visual direction for this site, which was specified before it was built and not proposed by the agent. Every phase was reviewed and accepted by hand before the next one started.

No code was reused. The idea of subtracting the examined set from a blast radius was developed in planning for this event.

Umbra

Finds the code an AI agent's change affects but the agent never looked at. A plugin for the Entire CLI. Deterministic, offline, and there is no model anywhere in it.
